# Numeric Clicker

Numeric Clicker is a client-side idle/collection game built with React + TypeScript.

## Features

- Coins and crystals economy
- Number collection from 1 to 100,000
- Rolling system with duplicate-to-crystal conversion
- Inventory sorting and search
- Crystal shop upgrades (coin multiplier, luck, multi-roll, auto-click)
- Local save with autosave and reset

## Scripts

- `npm run dev` - start development server
- `npm run build` - type-check and build production bundle
- `npm run lint` - run ESLint
- `npm run preview` - preview production build
